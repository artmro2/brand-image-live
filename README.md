# Brand Image Live

Static marketing site for Brand Image Live: on-site live laser engraving for trade shows, brand activations, and corporate events. Based in Chicago, available for travel.

Live site: https://artmro2.github.io/brand-image-live/

GitHub Pages serves this repository from the `main` branch at the repository root. Styles, scripts, images, and in-page links use relative paths so they resolve under `/brand-image-live/`.

## Quote form

The quote form checks each field in the browser and shows a confirmation on the page. Submissions are not delivered anywhere. No inbox is connected.

## Fonts

Cormorant Garamond and Outfit are included under the SIL Open Font License. License texts are in `fonts/`.
